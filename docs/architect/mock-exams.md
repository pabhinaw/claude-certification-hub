# Mock Exams <span class="level-badge">L4</span>

Three full-length practice exams, each with **60 original questions** weighted like the published domain split (27 / 18 / 20 / 20 / 15%), grouped by scenario theme, with an optional **120-minute timer**. When you finish, you get a score breakdown by domain and a full review with explanations.

!!! info "Before you start"
    * **Nothing is saved or sent anywhere.** Your answers stay in this browser tab, and refreshing the page clears them.
    * The three mocks share **no questions**, so each one is a fresh attempt.
    * Practice percentages are a guide only. The real exam uses a scaled score, so practice results can't be converted into an exam score.
    * These are original questions, **not** real or recalled exam items ([content policy](../resources/content-policy.md)).
