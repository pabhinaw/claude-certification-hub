# Contributing

This hub is meant to grow with the community. Contributions are welcome!

## Ways to help

* **Found an error or outdated fact?** Open a GitHub *Issue* with the page, what's wrong, and a link to the official source.
* **Want to improve a page?** Click the ✏️ edit icon at the top of any page. GitHub will guide you through a *pull request*.
* **Have a practice question?** It must be **original**: never share real exam questions (that violates the exam agreement).

## Content rules

1. **No real exam content.** Original material only.
2. **No personal data.** Use fictional IDs (`CUST-TEST-01`) and never real names, emails or account numbers.
3. **No secrets.** Never paste API keys, even revoked ones.
4. **Cite official docs** for technical facts that may change.
5. **Plain language first**, jargon second, so beginners can follow.
