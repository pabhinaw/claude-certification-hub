<p class="qb-meta"><span class="qb-id">D3-001</span><span>Quality hooks</span><span>Code generation with Claude Code</span><span title="Difficulty">●●○</span></p>

The team wants every file Claude edits to be formatted with Prettier, without exception. Best approach?

- **A.** A PostToolUse hook matching Edit|Write that runs Prettier on the edited file
- **B.** A custom /format command that engineers run after each session
- **C.** A Skill that describes the team's formatting rules in detail
- **D.** A line in CLAUDE.md: 'Always run Prettier on any file you edit'

??? success "Answer: A"
    **Why A is right:** 'Without exception' means a deterministic hook.

    * **B:** Relies on a person remembering.
    * **C:** Guidance, not enforcement.
    * **D:** Advisory.
