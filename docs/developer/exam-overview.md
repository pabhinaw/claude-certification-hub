# CCDV-F Exam Overview

| Item | Detail |
|---|---|
| Full name | Claude Certified Developer – Foundations |
| Code | **CCDV-F** |
| Questions | **53** (multiple choice and multiple response) |
| Time | **120 minutes** |
| Passing score | **720** / 1000 (scaled) |
| Price | about $125 USD (before partner discounts) |
| Validity | 12 months |
| Registration | Anthropic Partner Academy; delivered via Pearson VUE |
| Prerequisites | none formal |

## Recommended background

* 1–5 years of software engineering
* About 6 months working with Claude or similar LLM systems
* Python and/or TypeScript, REST APIs, command-line tools
* Working understanding of LLM fundamentals, agents, context management and MCP

## Domains and weights

| Domain | Weight | Topics |
|---|---|---|
| Applications & Integration | **33.1%** | API mechanics, application design, software-engineering foundations, configuration management |
| Model Selection & Optimisation | **16.8%** | LLM fundamentals, model trade-offs, cost and token management |
| Agents & Workflows | **14.7%** | agent architecture, building agents with Claude, patterns and frameworks |
| Prompt & Context Engineering | **11.0%** | context engineering, prompt engineering, output handling |
| Tools & MCPs | **10.6%** | tool implementation, MCP server development, agentic customisation |
| Security & Safety | **8.1%** | application security, guardrails, hooks, secrets and key management |
| Claude Code | **3.1%** | operating Claude Code |
| Eval, Testing & Debugging | **2.6%** | debugging and error handling |

The blueprint has 25 weighted sub-skills; the three biggest are all under *Applications & Integration*: Claude Application Design (~8.6%), Software Engineering Foundations (~7.4%) and Claude API Mechanics (~6.8%).

!!! tip "How it differs from Architect"
    Architect asks *which design is best*. Developer is more **code-first**: request/response shapes, SDK usage, streaming, error handling, caching, model choice and cost, secrets. A third of the exam is application and API mechanics.
