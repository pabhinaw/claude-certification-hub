# Mock Exams <span class="level-badge">L4</span>

Three full-length practice exams, each with **60 original questions** weighted like the published domain split (27 / 18 / 20 / 20 / 15%), grouped by scenario with the scenario shown above each question, and an optional **120-minute timer**. A fourth option, the **exam simulation**, builds a new paper each time from four randomly chosen scenarios. When you finish, you get a score breakdown by domain and a full review with explanations.

!!! info "Before you start"
    * **Nothing is saved or sent anywhere.** Your answers stay in this browser tab, and refreshing the page clears them.
    * The three mocks share **no questions**, so each one is a fresh attempt.
    * Practice percentages are a guide only. The real exam uses a scaled score, so practice results can't be converted into an exam score.
    * Each mock includes four **multiple-response** questions ("Select TWO"), which need every correct option for the mark.
    * The **exam simulation** follows the published structure: four of the six scenarios chosen at random, 15 questions each. Use it after the three fixed mocks, since it draws from the same bank.
    * These are original questions, **not** real or recalled exam items ([content policy](../resources/content-policy.md)).
