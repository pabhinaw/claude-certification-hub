## How to use the bank

1. **Answer before you open.** Commit to a choice, then expand the answer.
2. **Explain the wrong options.** Reading *why B, C and D fail* is where most of the learning is. Exam distractors are built from common misconceptions.
3. **Keep a miss log.** One line per miss: "what I believed → what is true". Re-read it on Days 8–10.
4. **Count lucky guesses as misses.** If you couldn't have explained it, you don't know it yet.
