# About this Hub

**Claude Certification Hub** is an independent, community learning platform for Anthropic's Claude certifications, developed by **[Prasoon Abhinaw](https://www.linkedin.com/in/pabhinaw/)**, a software engineer and Claude Certified Architect – Foundations. Connect on [LinkedIn](https://www.linkedin.com/in/pabhinaw/) · [Verify credential on Credly](https://www.credly.com/badges/b512d180-1dd7-4edb-8fb6-6251ec998635).

## Mission

Make high-quality preparation **free, structured and practical**: from first principles (L1) to exam-ready judgement (L4), with labs that build real skills.

## Principles

* **Accuracy**: technical claims link to official docs; corrections are welcome.
* **Originality**: no real exam questions, ever.
* **Privacy by default**: examples use fictional data only.
* **Beginner-friendly**: every advanced idea is reachable from a basic one.
