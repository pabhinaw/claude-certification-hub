<p class="qb-meta"><span class="qb-id">D5-001</span><span>Escalation</span><span>Customer support agent</span><span title="Difficulty">●○○</span></p>

Mid-conversation, a customer writes "Stop. I want to talk to a real person." The agent has a likely fix ready. What should happen?

- **A.** Escalate immediately with a structured handoff package
- **B.** Ask the customer to confirm they really want a human
- **C.** Run sentiment analysis to decide
- **D.** Apply the fix, then offer escalation if they're still unhappy

??? success "Answer: A"
    **Why A is right:** Explicit requests for a human are honoured immediately, with context passed on.

    **Why the others are wrong:**

    * **B:** Adds friction.
    * **C:** The explicit request is the trigger.
    * **D:** Ignores the explicit request.
