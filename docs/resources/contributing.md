# Contributing

The site gets better when people point out what's missing or wrong. Here's how to help.

## Ways to help

* **Have a question or suggestion?** Connect with the author on [LinkedIn](https://www.linkedin.com/in/pabhinaw/).
* **Found an error or outdated fact?** Send a message with the page name, what is wrong, and a link to the official source. Corrections are reviewed and credited in the [changelog](changelog.md) if you wish.
* **Used the hub for your exam?** Leave a comment on the [Learner Stories](../about/learner-stories.md) page.
* **Have a practice question to offer?** It must be **original**. Never share real or recalled exam questions: exam content is confidential under Anthropic's certification policy. See the [content policy](content-policy.md).

The source files for this site are maintained privately by the author, so contributions come in as suggestions and are added after review.

## Content rules

1. **No real exam content.** Original material only.
2. **No personal data.** Use fictional IDs (`CUST-TEST-01`) and never real names, emails or account numbers.
3. **No secrets.** Never paste API keys, even revoked ones.
4. **Cite official docs** for technical facts that may change.
5. **Plain language first**, jargon second, so beginners can follow.
